۱٫۱ خلاصه مدیریتی

یک فروشگاه اینترنتی تخصصی پوشاک کودک و نوجوان با سه تمایز اصلی نسبت به رقبا:

  1. سرعت انتشار محصول: از لحظه‌ای که فروشنده عکس خام محصول را می‌گیرد تا لحظه‌ای که محصول روی سایت و ۹ کانال اجتماعی منتشر می‌شود، کمتر از ۹۰ ثانیه — بدون دخالت انسان. رقبای ایرانی معمولاً ۱ تا ۳ روز زمان می‌برند.
  2. محتوای AI-native: توضیح محصول، راهنمای سایز، بلاگ تخصصی، کپشن، ویدئوی کوتاه و حتی پاسخ پشتیبانی، همه با موتور AI (AgentRouter) تولید می‌شوند. این یعنی هزینه تولید محتوا نزدیک به صفر و حجم محتوا ۱۰ برابر رقبا → سلطه سئویی.
  3. راهنمای سایز هوشمند و ضدمرجوعی: بزرگ‌ترین درد فروش آنلاین پوشاک کودک، اشتباه سایز و مرجوعی است. یک ماشین توصیه‌گر سایز بر اساس قد/وزن/سن + دیتای مرجوعی، نرخ مرجوعی را از ~۲۰٪ صنعت به زیر ۸٪ می‌رساند.

  3. درگاه پرداخت: فاز ۱ درگاه واسط (زرین‌پال/زیبال/آیدی‌پی) → فاز ۲ درگاه مستقیم بانکی پس از اینماد.
  4. مالیات: ثبت‌نام در سامانه مؤدیان، صدور صورتحساب الکترونیکی، مالیات بر ارزش افزوده.
  5. قانون تجارت الکترونیک: حق انصراف مصرف‌کننده، درج شفاف شرایط مرجوعی و گارانتی.
  6. الزام محتوایی: تصاویر و محتوای منطبق با ضوابط؛ برای پوشاک کودک معمولاً چالشی نیست ولی در انتخاب مدل کودک باید رضایت‌نامه ولی گرفته شود.

۲٫۱ تصمیم بنیادین: چرا معماری «هیبرید» و نه فقط Hostinger؟

شما گفتید سایت روی Hostinger باشد. این درست است، ولی برای فروش داخل ایران به‌تنهایی کافی نیست. دلایل:

۲٫۵ اتصال به AgentRouter

AgentRouter دو حالت سازگاری دارد:

# حالت OpenAI-compatible — مناسب برای کد فعلی شما که از پکیج openai استفاده می‌کند
OPENAI_BASE_URL=https://agentrouter.org/v1
OPENAI_API_KEY=<AgentRouter API Key>
OPENAI_MODEL=claude-opus-4-6

# حالت Anthropic-compatible — مخصوص Claude Code CLI (بدون /v1)
ANTHROPIC_BASE_URL=https://agentrouter.org
ANTHROPIC_AUTH_TOKEN=<AgentRouter API Key>
ANTHROPIC_MODEL=claude-opus-4-6

نکته مهم: مستندات AgentRouter تأکید می‌کند Base URL حالت Claude Code نباید /v1 داشته باشد و نباید با حالت OpenAI-compatible قاطی شود.

خبر خوب: پروژه فعلی شما همین الان OPENAI_BASE_URL و OPENAI_MODEL را می‌خواند، پس اتصال به AgentRouter بدون تغییر کد ممکن است.

نکته حیاتی: AgentRouter برای متن/کدنویسی است. برای تولید و ویرایش تصویر و تولید ویدئو به سرویس جداگانه نیاز داریم (جزئیات در سند ۳ و ۸).

لایه انتزاع اجباری: یک ماژول lib/ai/provider.ts می‌نویسیم که همه فراخوانی‌های AI از آن رد شود، با:
- انتخاب مدل بر اساس نوع کار (ارزان برای کپشن، قوی برای مقاله)
- Fallback خودکار به provider دوم اگر AgentRouter پاسخ نداد
- کش پاسخ‌های تکراری در Redis (کاهش هزینه تا ۴۰٪)
- سقف مصرف روزانه و لاگ هزینه

۲٫۸ امنیت

  • SSH فقط با کلید، پورت غیر پیش‌فرض، fail2ban، UFW
  • جداسازی کامل کلیدها: هیچ کلیدی در گیت — فقط .env روی سرور با دسترسی ۶۰۰
  • نقش‌های کاربری: owner / admin / seller / support / viewer با RBAC
  • رمزنگاری توکن‌های شبکه‌های اجتماعی در دیتابیس (AES-256 با کلید در env)
  • Rate limit روی API عمومی و لاگین (Redis-based)
  • لاگ حسابرسی (audit log) برای هر تغییر قیمت، موجودی و انتشار

۲٫۹ عملکرد (Performance)

هدف: LCP زیر ۲٫۵ ثانیه روی موبایل ایرانی با اینترنت متوسط.

  • ISR برای صفحات محصول و دسته (revalidate ۶۰ ثانیه)
  • تصاویر: WebP/AVIF، سه سایز، next/image + کش CDN طولانی
  • فونت فارسی محلی (وزیرمتن/ایران‌سنس) با font-display: swap

  • بودجه عملکرد در CI: هر PR که Lighthouse را زیر ۹۰ ببرد، fail شود

۲٫۱۰ برنامه تداوم کسب‌وکار (قطعی اینترنت)

سه سطح تخریب کنترل‌شده:

  1. سطح سبز (عادی): همه‌چیز روی Hostinger، CDN ایران جلو.
  2. سطح زرد (کندی بین‌الملل): CDN از کش سرو می‌کند؛ صفحات محصول تا ۲۴ ساعت از کش. سفارش‌گیری از Relay ایران با صف آفلاین.
  3. سطح قرمز (قطع کامل بین‌الملل): آینه ایرانی فعال می‌شود — نسخه استاتیک کاتالوگ + فرم سفارش + پرداخت داخلی. اتوماسیون خارجی متوقف، کانال‌های داخلی (بله/ایتا/روبیکا/پیامک) فعال می‌مانند. همگام‌سازی سفارش‌ها پس از بازگشت اتصال.

هاست‌های ایرانی در دوره‌های محدودیت شدید اینترنت به‌مراتب در دسترس‌تر بوده‌اند (مرجع)، به همین دلیل لایه ایران در معماری «اختیاری» نیست.

ایستگاه ۱ — ورودی عکس (سه مسیر ورود)

فروشنده هر کدام را که راحت‌تر بود انتخاب می‌کند؛ هر سه به یک endpoint واحد می‌رسند: POST /api/ingest/photos.

مسیر A — PWA موبایل (توصیه‌شده، فاز ۱)

اپ وب نصب‌شدنی روی موبایل. صفحه /(seller)/upload:
- دکمه بزرگ «عکس بگیر یا انتخاب کن» (چندتایی، تا ۸ عکس)
- راهنمای زنده عکاسی: کادر شبح‌مانند + هشدار «نور کم است» / «تصویر تار است» (تشخیص محلی با Canvas)
- سه فیلد اختیاری: قیمت خرید، تعداد موجودی، یادداشت صوتی 🎤
- آپلود پس‌زمینه با صف آفلاین (Service Worker) — اگر نت قطع شد، بعداً خودکار می‌فرستد
- بعد از آپلود، فروشنده هیچ کار دیگری ندارد؛ نوتیف می‌گیرد: «محصول منتشر شد ✅»

مسیر B — ربات تلگرام (سریع‌ترین برای پیاده‌سازی)

۴٫۱ استراتژی کانالی

۴٫۷ رشد ارگانیک اینستاگرام (بدون تبلیغ)

Google Search Console (حیاتی و رایگان)، Google Trends ایران، Keyword Planner، AnswerThePublic، جستجوهای مرتبط گوگل، سؤالات مشتری در چت‌بات (بهترین منبع کلیدواژه واقعی!)، رصد رقبا.

گوگل با محتوای AI مشکلی ندارد؛ با محتوای بی‌ارزش مشکل دارد. پس:
