# پروژه فروشگاه پوشاک کودک و نوجوان — مستند مادر

این پوشه، بیزینس‌پلن و طرح اجرایی کامل راه‌اندازی یک فروشگاه اینترنتی پوشاک کودک و نوجوان روی زیرساخت **Hostinger VPS** است؛ با تمرکز بر:

- فروش داخل ایران (درگاه پرداخت، اینماد، ارسال، مالیات)
- اتوماسیون کامل «عکس → محصول → پست شبکه‌های اجتماعی → تبلیغ»
- سئو و بک‌لینک درجه‌یک
- استفاده از حساب **AgentRouter** به عنوان موتور هوش مصنوعی (تولید محتوا، توضیح محصول، کپشن، سناریوی ویدئو)
- بازاستفاده از تجربه و کد موجود پروژه `ehsansalehi.ir` (خبرخوان، سیستم انتشار خودکار تلگرام/بله/ایتا/روبیکا/لینکدین/اینستاگرام، واترمارک، پنل ادمین، دیپلوی cPanel/VPS)

## خلاصه یک‌صفحه‌ای (TL;DR)

**نام کاری پیشنهادی:** یک برند دو-سیلابی فارسی/لاتین کوتاه (مثلاً «کیدزلی / Kidsly»، «توپولی»، «نی‌نی‌مد») — انتخاب نهایی در سند ۱۰.

**مدل:** فروشگاه آنلاین + انبار سبک (Light Stock) + دراپ‌شیپینگ از تولیدکننده‌های تهران/تبریز + کانال‌های اجتماعی به‌عنوان موتور اصلی ترافیک.

**زیرساخت:** Hostinger VPS (KVM 2 یا KVM 4) با Docker + Coolify؛ Next.js 16 (همان استک فعلی شما) + MySQL/MariaDB + Redis + MinIO (تصاویر) + n8n (ارکستراسیون اتوماسیون) + AgentRouter (مغز AI).
**نکته حیاتی:** برای فروش داخل ایران، یک **لایه ایرانی** (دامنه .ir + CDN ابرآروان + یک VPS کوچک ایران به عنوان Relay درگاه پرداخت و پیامک) در کنار Hostinger الزامی است. دلیل کامل در سند ۲.

**اتوماسیون هدف:** فروشنده فقط ۳ تا ۸ عکس خام از محصول را در اپ موبایل/پنل آپلود می‌کند →
۱) حذف پس‌زمینه و استانداردسازی تصویر، ۲) تشخیص نوع لباس/رنگ/سایز با AI، ۳) تولید عنوان و توضیح سئوشده فارسی، ۴) قیمت‌گذاری پیشنهادی، ۵) ساخت محصول در سایت، ۶) ساخت کپشن + هشتگ برای هر شبکه، ۷) ساخت ویدئوی کوتاه (Reels/Shorts) از همان عکس‌ها، ۸) زمان‌بندی و انتشار در اینستاگرام، تلگرام، بله، ایتا، روبیکا، واتساپ‌چنل، پینترست، یوتیوب‌شورتس، آپارات، ۹) ثبت لاگ و گزارش عملکرد. کل مسیر: زیر ۹۰ ثانیه بدون دخالت انسان.

**هزینه راه‌اندازی تخمینی:** ۹۵ تا ۲۸۰ میلیون تومان بسته به سناریو (جدول کامل در سند ۱).
**نقطه سر‌به‌سر تخمینی:** ماه ۵ تا ۷ با میانگین ۳۵۰ سفارش در ماه و AOV حدود ۱٫۸ میلیون تومان.
