# سند ۳ — پایپ‌لاین اتوماسیون: از «چند عکس ساده» تا محصول + پست + ویدئو

این سند قلب پروژه است. خواسته اصلی شما:

> «فروشنده فقط با چند تا عکس ساده که برای سایت می‌فرسته یا توی پنل می‌ذاره یا حتی اپلیکیشن موبایل، محصول روی سایت بره و پست بشه روی شبکه‌های اجتماعی.»

## ۳٫۰ نگاه کلی: خط تولید ۹ ایستگاهی

```
[۱] ورودی عکس  →  [۲] پاکسازی تصویر  →  [۳] درک محصول با AI  →  [۴] غنی‌سازی داده
      ↓
[۵] ساخت محصول در سایت  →  [۶] تولید محتوای اجتماعی  →  [۷] ساخت ویدئو کوتاه
      ↓
[۸] زمان‌بندی و انتشار چندکاناله  →  [۹] رصد، یادگیری و بهینه‌سازی خودکار
```

**زمان کل هدف:** ۶۰ تا ۹۰ ثانیه از آپلود تا انتشار.
**دخالت انسان:** صفر در حالت Auto؛ یک کلیک تأیید در حالت Review.

## ایستگاه ۱ — ورودی عکس (سه مسیر ورود)

فروشنده هر کدام را که راحت‌تر بود انتخاب می‌کند؛ هر سه به یک endpoint واحد می‌رسند: `POST /api/ingest/photos`.

### مسیر A — PWA موبایل (توصیه‌شده، فاز ۱)
اپ وب نصب‌شدنی روی موبایل. صفحه `/(seller)/upload`:
- دکمه بزرگ «عکس بگیر یا انتخاب کن» (چندتایی، تا ۸ عکس)
- راهنمای زنده عکاسی: کادر شبح‌مانند + هشدار «نور کم است» / «تصویر تار است» (تشخیص محلی با Canvas)
- سه فیلد اختیاری: قیمت خرید، تعداد موجودی، یادداشت صوتی 🎤
- آپلود پس‌زمینه با صف آفلاین (Service Worker) — اگر نت قطع شد، بعداً خودکار می‌فرستد
- بعد از آپلود، فروشنده هیچ کار دیگری ندارد؛ نوتیف می‌گیرد: «محصول منتشر شد ✅»

### مسیر B — ربات تلگرام (سریع‌ترین برای پیاده‌سازی)
فروشنده عکس‌ها را داخل یک گروه/بات تلگرام می‌فرستد، کپشن دلخواه مثل `120 قیمت:850 تعداد:12`. ربات همان پایپ‌لاین را trigger می‌کند و لینک محصول را برمی‌گرداند.
> این مسیر را **اول** بسازید: در ۲ روز کار می‌کند و فروشنده هیچ آموزشی لازم ندارد.

### مسیر C — پنل وب دسکتاپ
Drag & Drop چندتایی + آپلود دسته‌ای اکسل برای ورود انبوه محصولات.

### یادداشت صوتی → متن
اگر فروشنده صوت فرستاد (مثلاً «شلوار جین پسرانه، سایز ۶ تا ۱۲، جنس کش‌دار، قیمت ۸۵۰»)، با Speech-to-Text به متن تبدیل و به‌عنوان context به AI داده می‌شود. این کیفیت خروجی را چشمگیر بالا می‌برد.

## ایستگاه ۲ — پاکسازی و استانداردسازی تصویر (خودکار)

روی worker با Sharp + rembg:

| مرحله | عملیات |
|---|---|
| ۱ | تشخیص و چرخش خودکار (EXIF) |
| ۲ | حذف پس‌زمینه (rembg / u2net) → پس‌زمینه سفید یا رنگ برند |
| ۳ | برش هوشمند و مرکزچین کردن سوژه با حاشیه یکسان |
| ۴ | اصلاح نور، کنتراست و وایت‌بالانس خودکار |
| ۵ | حذف نویز و شارپن ملایم |
| ۶ | خروجی چندسایزی: `2000×2000` (زوم)، `1200×1200` (گالری)، `600×600` (لیست)، `1080×1350` (اینستا پست)، `1080×1920` (استوری/ریلز) |
| ۷ | واترمارک ظریف برند (بازاستفاده از `app/lib/watermark.ts`) |
| ۸ | تبدیل به WebP + AVIF و آپلود در فضای ذخیره (فاز cPanel: `public/uploads` + CDN؛ فاز VPS: MinIO) |
| ۹ | امتیاز کیفیت (۰-۱۰۰)؛ زیر ۵۰ → درخواست عکس مجدد از فروشنده |
| ۱۰ | ⭐ **تولید لایه شفاف پرو آنلاین** — همان خروجی مرحله ۲ با نقاط لنگر، ذخیره در `tryon_assets` (هزینه اضافی: صفر) |

**ارتقای اختیاری (فاز ۲):** تولید عکس «روی مانکن/مدل» با سرویس AI تصویر — از عکس ساده روی زمین، تصویر لایف‌استایل بسازد. تأثیر بزرگی روی نرخ تبدیل دارد. (نیاز به سرویس تصویر جدا از AgentRouter)

## ایستگاه ۳ — درک محصول با AI (Vision)

مدل چندوجهی (Vision) عکس‌ها را می‌بیند و JSON ساختاریافته برمی‌گرداند:

```jsonc
{
  "category": "شلوار",           // تیشرت|شلوار|پیراهن|سرهمی|ست|کاپشن|...
  "gender": "پسرانه",            // پسرانه|دخترانه|یونیسکس
  "age_group": "۶ تا ۱۲ سال",
  "colors": ["سرمه‌ای", "آبی روشن"],
  "pattern": "ساده",
  "fabric_guess": "جین کش‌دار",
  "season": "پاییز و زمستان",
  "style_tags": ["اسپرت", "روزمره", "مدرسه"],
  "occasions": ["مدرسه", "گردش"],
  "features": ["جیب‌دار", "کمر کش", "دکمه فلزی"],
  "quality_flags": [],           // مثلاً "تصویر تار" | "نور ناکافی"
  "confidence": 0.93
}
```

**پرامپت سیستمی نمونه:**
```
تو یک متخصص مرچندایزینگ پوشاک کودک هستی. از روی تصاویر، ویژگی‌های محصول را استخراج کن.
فقط JSON معتبر بده. اگر مطمئن نیستی مقدار را null بگذار و confidence را پایین بیاور.
واحد سن بر اساس استاندارد ایران باشد. رنگ‌ها را با نام فارسی رایج بازار بنویس.
```

اگر `confidence < 0.7` → محصول به صف «نیازمند بازبینی» می‌رود و به فروشنده نوتیف داده می‌شود.

## ایستگاه ۴ — غنی‌سازی داده و قیمت‌گذاری

## ایستگاه ۵ — ساخت محصول در سایت

AI با ورودی ایستگاه ۳ و ۴ این‌ها را تولید می‌کند:

- **عنوان سئو‌شده** (۵۰-۶۰ کاراکتر): «شلوار جین پسرانه کش‌دار مدل آرش — ۶ تا ۱۲ سال»
- **توضیح کوتاه** (۲ خط برای کارت محصول)
- **توضیح کامل** (۳۰۰-۵۰۰ کلمه): جنس، حس پارچه، مناسب چه فصلی، نکات نگهداری و شست‌وشو، چرا برای کودک مناسب است
- **بولت‌پوینت ویژگی‌ها** (۵ تا ۷ مورد)
- **متا تایتل و متا دیسکریپشن**
- **FAQ اختصاصی محصول** (۴ سؤال — برای ریچ‌اسنیپت گوگل)
- **Alt text** برای هر تصویر
- **اسکیمای JSON-LD**: `Product` + `Offer` + `AggregateRating` + `FAQPage`
- **Slug فارسی-فرندلی**

سپس رکورد در `products` ساخته می‌شود، ایندکس MeiliSearch به‌روز می‌شود، سایت‌مپ رفرش می‌شود و به گوگل (Indexing API / IndexNow) پینگ زده می‌شود.

**قانون ضدجریمه‌ی گوگل:** هرگز دو محصول با توضیح یکسان منتشر نشود — هش شباهت متنی محاسبه می‌شود؛ اگر شباهت بالای ۸۵٪ بود، بازتولید انجام می‌گیرد.

هشتگ‌ها را در سه گروه بده: پرترافیک، متوسط، نیچ.

## ایستگاه ۷ — تولید ویدئوی کوتاه خودکار (Reels/Shorts)

خواسته شما: «حتی ویدئوها هم پست بشه».

**⚠️ وابستگی به مرحله زیرساخت (سند ۲):** FFmpeg روی هاست اشتراکی cPanel معمولاً در دسترس نیست. بنابراین:

| مرحله زیرساخت | راهکار ویدئو |
|---|---|
| **مرحله ۱ (cPanel)** | الف) **کاروسل متحرک** (اسلایدشو WebP/GIF) با Sharp — روی cPanel کار می‌کند و برای اینستاگرام و تلگرام تقریباً همان تأثیر را دارد؛ ب) رندر در مرورگر با Canvas/WebCodecs در پنل ادمین؛ ج) سرویس ابری رندر (~۵-۲۰ سنت هر ویدئو) |
| **مرحله ۲ (هیبرید)** | FFmpeg روی VPS کوچک اختصاصی رندر — نامحدود و رایگان |
| **مرحله ۳ (VPS)** | FFmpeg کامل با صف موازی |

متغیر `VIDEO_DRIVER` در `.env` تعیین می‌کند کدام مسیر فعال باشد — بقیه کد یکسان می‌ماند.

توضیحات زیر معماری کامل (مرحله ۲ و ۳) را شرح می‌دهد:

### الگوهای ویدئویی آماده (Template Engine)

| قالب | ساختار | مناسب |
|---|---|---|
| `showcase` | Ken Burns روی ۴ عکس + متن روی تصویر + موزیک | محصول تکی |
| `before-after` | عکس خام ← عکس استایل‌شده | جذابیت بصری |
| `size-guide` | انیمیشن جدول سایز | آموزشی |
| `carousel-3` | ۳ محصول مکمل («ست کن!») | افزایش AOV |
| `sale-countdown` | تایمر + قیمت قبل/بعد | کمپین |
| `ugc-style` | عکس + متن دست‌نویس‌مانند + ترنزیشن سریع | ترند اینستاگرام |
| `story-poll` | استوری تعاملی «کدوم رنگ؟» | تعامل |

### پایپ‌لاین رندر
```
عکس‌های استاندارد + متن AI + موزیک بی‌کلام + قالب
        ↓ FFmpeg (zoompan, drawtext, xfade, aformat)
   ویدئو ۱۰۸۰×۱۹۲۰، ۳۰fps، ۷-۱۵ ثانیه، H.264, <8MB
        ↓
  زیرنویس فارسی برنت-این (چون اکثر کاربران بدون صدا می‌بینند)
```

**نکته حقوقی:** فقط موزیک بدون کپی‌رایت (کتابخانه محلی از ۵۰ ترک royalty-free) — یا برای اینستاگرام از موزیک ترند داخل خود اپ در حالت نیمه‌خودکار.

**سناریوی ویدئو با AI:** AgentRouter برای هر محصول یک اسکریپت ۳ سکانسی می‌نویسد (هوک ۰-۲ث، ویژگی ۲-۸ث، CTA ۸-۱۲ث) که به‌عنوان متن روی ویدئو رندر می‌شود.

## ایستگاه ۸ — زمان‌بندی و انتشار چندکاناله

### موتور صف انتشار
هر پست یک رکورد در جدول `social_queue` است با: کانال، زمان هدف، محتوا، وضعیت، تعداد تلاش.

### قوانین زمان‌بندی هوشمند
- **پنجره‌های طلایی ایران:** ۱۰:۰۰-۱۱:۳۰، ۱۳:۳۰-۱۵:۰۰، **۲۱:۰۰-۲۳:۳۰ (بهترین)**
- سقف روزانه هر کانال: اینستاگرام ۲ پست + ۵ استوری، تلگرام ۴، بله/ایتا/روبیکا ۳، پینترست ۱۰
- فاصله حداقل ۹۰ دقیقه بین پست‌های اینستاگرام (جلوگیری از شادوبن)
- اگر ۵ محصول هم‌زمان آپلود شد → روی ۳ روز پخش می‌شود، نه یک‌جا
- تعطیلات و مناسبت‌های ایرانی از تقویم داخلی خوانده می‌شود (کمپین خودکار)

### انتشار
بازاستفاده و توسعه `app/lib/socialPoster.ts` فعلی که همین حالا تلگرام، بله، ایتا، روبیکا، لینکدین، فیسبوک، اینستاگرام و واتساپ را پشتیبانی می‌کند. اضافه می‌شود: پینترست، یوتیوب، آپارات، X.

**مدیریت خطا:** ۳ بار تلاش با backoff نمایی → در صورت شکست، ثبت در `social_failures` و اعلان به ادمین در تلگرام. هرگز پست ناقص منتشر نشود.

**Idempotency:** هر پست یک کلید یکتا `{product_id}:{channel}:{template}` دارد تا پست تکراری منتشر نشود.

## ایستگاه ۹ — رصد، یادگیری و بهینه‌سازی خودکار

- هر ۶ ساعت آمار هر پست (لایک، سیو، اشتراک، کلیک، فروش منتسب) جمع می‌شود
- لینک‌ها با UTM و کوتاه‌کننده اختصاصی (`s.brand.ir/xxxx`) ردیابی می‌شوند
- سیستم یاد می‌گیرد: کدام لحن کپشن، کدام قالب ویدئو، کدام ساعت، کدام دسته بهترین عملکرد را دارد
- هفتگی: گزارش خودکار «۵ پست برتر / ۵ پست ضعیف + توصیه» به تلگرام مدیر
- **بازنشر هوشمند:** محصولاتی که در ۳۰ روز نفروخته‌اند، با کپشن و قالب متفاوت دوباره منتشر می‌شوند
- **A/B تست خودکار:** برای ۲۰٪ محصولات، دو نسخه کپشن ساخته و برنده انتخاب می‌شود

## ۳٫۱۰ محتوای غیرمحصولی خودکار (مطالب جالب و ویدئوهای آموزشی)

خواسته شما: «مطالب جالب در خصوص پوشاک کودک و نوجوان هم پست بشه». این یک پایپ‌لاین جدا و روزانه است — دقیقاً مشابه سیستم اخبار خودکاری که در `ehsansalehi.ir` ساخته‌اید (`app/api/cron/news`).

| شنبه | راهنمای خرید | «چطور سایز درست لباس بچه رو انتخاب کنیم؟» |
| یکشنبه | ترند مد کودک | «رنگ‌های محبوب پاییز امسال برای بچه‌ها» |
| دوشنبه | نکته سلامت و پارچه | «چرا پنبه ۱۰۰٪ برای پوست حساس کودک بهتره؟» |
| سه‌شنبه | استایل‌گاید | «۵ ست مدرسه برای دختر ۹ ساله» |
| چهارشنبه | محتوای تعاملی | نظرسنجی، کوییز سایز، مسابقه عکس |
| پنجشنبه | UGC و رضایت مشتری | بازنشر عکس مشتری‌ها با اجازه |
| جمعه | سرگرمی و احساسی | ویدئوی بامزه، نکته تربیتی سبک |

### منابع محتوا
1. **تولید کامل با AgentRouter** بر اساس بانک ۳۰۰ موضوع از قبل تعریف‌شده (Content Bank)
2. **رصد ترند:** Google Trends ایران + هشتگ‌های اینستاگرام + سؤالات پرتکرار مشتری‌ها در چت‌بات
3. **بازنویسی منابع بین‌المللی:** RSS از مجلات مد کودک — بازنویسی کامل فارسی و بومی‌سازی (نه ترجمه ماشینی)
4. **دیتای خود سایت:** «پرفروش‌ترین‌های این هفته»، «محصولات جدید»

هر مطلب: ۱ مقاله بلاگ (۱۰۰۰-۱۵۰۰ کلمه سئوشده) + ۱ کاروسل اینستاگرام + ۱ ریلز + ۱ پست تلگرام + ۱ پین پینترست. یعنی **یک ورودی، پنج خروجی**.

### کنترل کیفیت محتوای AI
- ممنوعیت ادعای پزشکی و درمانی
- ممنوعیت آمار بدون منبع
- بررسی خودکار تکراری‌بودن با محتوای قبلی سایت
- امتیاز خوانایی فارسی (طول جمله، جملات مجهول)
- نمونه‌گیری ۱۰٪ برای بازبینی انسانی هفتگی

## ۳٫۱۳ ارکستراسیون: کد اختصاصی حالا، n8n بعداً

**مرحله ۱ (cPanel) — بدون n8n:**
- صف کارها در جدول MySQL `job_queue` (سند ۹) + Cron هر ۵ دقیقه
- سناریوها به‌صورت کد در `lib/workflows/` — هر سناریو یک فایل TypeScript
- کاملاً روی هاست اشتراکی کار می‌کند، صفر هزینه اضافه
- عیب: برای تغییر سناریو باید دیپلوی کنید (که با CI/CD شما ۲ دقیقه است)

**مرحله ۲ و ۳ — افزودن n8n:**
- سناریوهای بازاریابی که مدام تغییر می‌کنند به n8n منتقل می‌شوند تا بدون دیپلوی قابل ویرایش باشند
- مسیرهای حیاتی و پرسرعت در کد می‌مانند

اجرای n8n روی VPS به‌جای n8n Cloud، صرفه‌جویی قابل توجهی دارد (حدود ۶٫۵ دلار در ماه در برابر ۲۰ تا ۶۶۷ دلار) و محدودیت اجرا هم ندارد ([مرجع](https://ivristech.com/n8n-self-hosting-hostinger/)).
